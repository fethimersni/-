# مفكرة الأستاذ: بناء ملف APK عبر GitHub

## الخطوات
1. أنشئ حسابًا على github.com، ثم مستودعًا جديدًا (New repository) باسم mofakkira، واختر **Private** (المستودع يحوي مفتاح التوقيع).
2. ارفع محتويات هذا المجلد: في صفحة المستودع اختر "uploading an existing file" واسحب كل الملفات والمجلدات، ثم Commit changes.
   - تأكد أن المجلد المخفي `.github` ظهر في المستودع. وإن لم يظهر: Add file ← Create new file، واكتب في خانة الاسم `.github/workflows/build-apk.yml`، والصق محتوى الملف نفسه، ثم Commit.
3. افتح تبويب **Actions**. يبدأ تشغيل "Build APK" تلقائيًا ويستغرق 5 إلى 10 دقائق. عند اكتماله افتحه، وحمّل **mofakkira-apk** من قسم Artifacts.
4. فكّ الضغط، وانقل `app-debug.apk` إلى الهاتف وافتحه، واسمح بالتثبيت من مصدر غير معروف إن طُلب.

## التحديث لاحقًا
عدّل `www/index.html` في GitHub (أيقونة القلم) ثم Commit. يُبنى APK جديد تلقائيًا، فثبّته فوق القديم. تبقى بياناتك لأن التوقيع ثابت (ملف `debug.keystore`).

## نقل بياناتك من النسخة الويب
في النسخة القديمة: إعدادات ← انسخ نص النسخة الاحتياطية. وفي التطبيقة الجديدة: الصقه في الخانة نفسها واضغط «استيراد».

## تحذيرات
- خذ نسخة احتياطية قبل حذف التطبيقة من الهاتف، فالحذف يمسح بياناتها.
- إذا فشل البناء، افتح تشغيل Actions الفاشل وانسخ رسالة الخطأ الأخيرة وأرسلها إليّ.
